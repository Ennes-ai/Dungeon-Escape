DUNGEON ESCAPE
==============

rogulike tarzında küçük pygame Zero ile yapılmış oyun.
8 tane coin'i topla goblin ve iskeletlerden kaç, çıkışa ulaş.


Kullanılan Kütüphaneler
--------------
- Pygame Zero (pgzero)
- math
- random


Nasıl çalıştırılır?
----------
1.Pygame Zero yükle:
       pip install pgzero
2. src klasöründen çalıştır:
       cd src
       python main.py


Kontroller
--------
yön tuşları / WASD : hareket et
ESC : durdur  / devam et



RULES
-----
- 3 can ile başlıyorsun düşmanlara çarparsan canın azalır iksir içersen canın 1 artar
- kazanmak için tüm paraları toplarla ve çıkışa git.
- tüm kalplerin giderse kaybedersin.
